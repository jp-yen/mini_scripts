細かい条件でフォントを選択できる、**フォント検索・プレビューアプリの設計仕様および実装方針**です。

---

### 動作環境・開発要件

#### 1. コンパイル（ビルド）環境
* **ターゲットフレームワーク:** .NET 10.0 (`net10.0-windows`)
* **開発・ビルドツール:**
  * .NET 10.0 SDK (`dotnet CLI`)
  * Visual Studio 2026 / Visual Studio 2022 最新プレビュー（.NET 10 対応版）、または VS Code + C# Dev Kit
* **主要外部依存パッケージ (NuGet):**
  * `CommunityToolkit.Mvvm` (8.4.2)
  * `Microsoft.Web.WebView2` (1.0.*)
  * `Microsoft.Extensions.DependencyInjection` (9.*)
* **ビルドスクリプト:**
  * `build.bat`（Self-Contained 単一実行ファイル、x64、デバッグシンボル除去）

#### 2. 実行環境
* **対応 OS:** Windows 10 (バージョン 1809 / Build 17763 以降) または Windows 11 (64-bit / x64)
  * ※ Windows 11 (Build 22000+) では DWM API によるタイトルバー背景色・テキスト色の完全連動に対応。
* **ランタイム要件:**
  * **配布版 (`publish\FontSelector.exe`):** 自己完結型（Self-Contained）のため、**.NET ランタイム未インストールの環境でも単体動作可能**。
  * **開発ビルド (`dotnet build` 版):** .NET 10.0 Desktop Runtime (x64) が必要。
* **WebView2 ランタイム:** Microsoft Edge WebView2 Evergreen ランタイム（Windows 10/11 に標準付属・自動更新）。
* **画面要件:** ディスプレイ解像度 1280×720 以上推奨（Per-Monitor V2 高DPIスケーリング対応）。

### アプリケーション画面・UI構成

1. **上部検索・フィルターバー (`SearchBarControl` / `FilterBarControl`)**
   * テキスト検索（リアルタイム）および各種属性による絞り込み。
2. **メイン領域（左右分割スプリッター）**
   * **左側: フォントファミリー一覧 (`FontListControl`)**
     * システムフォントをフォントファミリー単位に集約表示（Excel / Photoshop 準拠）。
     * 各項目にファミリー名、所属書体数バッジ（例: `8 書体`）、および代表書体（Regular/Normal 優先）によるサンプル文字列を表示。
   * **右側: プレビュー領域 (`PreviewControl`)**
     * **クイック操作バー:** ファミリー名、スタイル切替プルダウン（太さ昇順 ＞ スタイル順）、コピーボタン群（フォント名 / CSS / パス）。
     * **WebView2 プレビューキャンバス:** フルカラー絵文字（COLRv1 / SVG）および高精度組版。
     * **フォント微調整パネル:** サイズ (10〜72pt)、太さ (wght: 100〜900)、文字幅 (wdth: 50〜150%)、傾き (slnt: oblique角度)、イタリックチェックボックス (ital)、リセットボタン。
     * **テキスト入力エリア:** プレビューテキストの手動編集、言語別文例セット、Unicode 1.1〜16.0 絵文字文例セット、類似文字視認性比較文例。
3. **下部情報パネル (`FontInfoPanelControl`)**
   * 選択中フォントのメタデータ一覧（フォントファミリー、太さ、スタイル、分類、文字幅、言語、バージョン、提供元、形式、アウトライン、配置先、機能、バリアブル対応）。
   * **言語タグ:** 各言語名がインタラクティブなチップボタンになっており、クリックで該当言語のフィルターを直接適用・解除可能（選択中言語はアクセントカラーで強調表示）。
4. **ステータスバー**
   * 該当件数表示（例: `該当: 12 ファミリー (45 書体) / 全 350 ファミリー (2,863 書体)`）、クリップボードコピー通知。

### フィルター構成一覧

#### 1. テキスト検索（リアルタイム・全単語一致）

* **対象:** フォントファミリー名（日本語 / 英語 / 別名）、書体表示名、フォントファイル名、提供元

#### 2. ドロップダウンフィルター（フィルターバー 1行目・3行目）

* **言語 (Language):**
  * 日本語、英語 / ラテン文字、中国語（簡体字 / 繁体字）、韓国語、キリル文字、ギリシャ文字、アラビア文字 など
* **分類 (Category):**
  * 明朝 / セリフ系、ゴシック / サンセリフ系、等幅、装飾 / 見出し系、手書き / 筆記体、記号 / シンボル
* **文字幅 (Spacing):**
  * 可変幅 (Proportional) / 等幅 (Monospace)
* **太さ (Weight):**
  * Thin (100) 〜 Regular (400) 〜 Bold (700) 〜 Black (900)
* **スタイル (Style):**
  * Normal（直立） / Italic（イタリック体） / Oblique（斜体）
* **字幅 (Stretch):**
  * Condensed（狭幅） / Normal（標準） / Expanded（広幅）
* **形式 (File Format):**
  * TrueType (`.ttf`) / OpenType (`.otf`) / Font Collection (`.ttc` / `.otc`)
* **アウトライン (Outline Format):**
  * TrueType / PostScript (CFF/CFF2) / OpenType Layout (GSUB/GPOS)
* **提供元 (Vendor):**
  * Microsoft, Adobe, Google, Morisawa, JustSystems, 個人製作者 など
* **配置先 (Install Type):**
  * OS標準付属 (`C:\Windows\Fonts` 標準)
  * System（システム全体手動インストール / `C:\Windows\Fonts`）
  * User（現在のユーザーのみ手動インストール / `%LOCALAPPDATA%\Microsoft\Windows\Fonts`）
* **文字セット (Character Set):**
  * **JIS第1水準 (常用漢字):** 亜〜腕などの日常漢字を網羅
  * **JIS第2水準 (人名・旧字):** 弌〜熙などの人名用・旧字体漢字
  * **JIS第3・第4水準 (JIS2004拡張):** 俱、剝、髙、𠮷（サロゲートペア）等の拡張漢字
  * **絵文字 (Emoji):** Unicode 絵文字およびカラー絵文字を収録するフォント

#### 3. 機能チェックボックス（フィルターバー 2行目）

* **Nerd Fonts:** パッチ済みアイコン（`\uf000` 〜）の有無
* **合字 (リガチャ):** `!=`, `=>`, `===` などのプログラミング結合表示（`calt` / `liga`）
* **斜線ゼロ:** 斜線入りゼロ（`0`）の対応（`zero`）
* **バリアブルフォント:** 太さや幅を無段階調整できる規格（`fvar` テーブル保持）
* **異体字 (IVS):** 住民基本台帳対応の人名・地名等の字形セレクタ（cmap Format 14）

#### 4. フィルターと書体（スタイル）プルダウンの連動

* **ファミリー内書体のグレーアウト表示:**
  * プレビュー上部の書体プルダウンでは、ファミリー内の全書体を表示しつつ、現在アクティブなフィルター条件（言語・文字セット・太さ・スタイル等）に合致しない書体は自動的に**グレー表示（選択不可）**となり、ツールチップで非適合理由を表示します。
  * フィルター条件変更時、選択中の書体が非適合となった場合は、ファミリー内の適合書体（Regular/Normal を優先）へ自動的に再選択され、豆腐（`□`）表示を防止します。

### 下部詳細パネル（メタデータ表示項目）

フィルターバーによる絞り込みのほか、フォント選択時に下部詳細パネルで以下の属性を表示・確認できます：

* **フォントファミリー:** 日英のファミリー名（例: `游ゴシック / Yu Gothic`）＋「📋」コピーボタン
* **太さ / スタイル / 分類 / 文字幅 / 言語**
* **バージョン / 提供元 / 形式 / ファイル名 / アウトライン / 配置先**
* **機能 (Features):**
  * 収録漢字水準: JIS第1〜第4水準
  * 組み字・特殊機能: 異体字(IVS)、絵文字、合字、斜線ゼロ、スモールキャプス (`smcp`)、オールドスタイル数字 (`onum`)、異体字セット (`ss01`〜`ss20`)
* **バリアブル (Variable):** 対応可変軸サマリー（例: `対応 (wght: 100〜900 / wdth: 75〜100 / slnt: -20〜20)`）
* **ライセンス:** 商用利用可, オープンソース（SIL OFL 等）, フリーウェア等のライセンス文字列

### コピー機能の仕様

* **プレビュー上部「📋 フォント名をコピー」:**
  * プルダウンで選択されたスタイルを含む完全なフォント名（例: `游ゴシック Oblique`, `Segoe UI Bold`）をクリップボードにコピー。
* **下部詳細「フォントファミリー: 」横「📋」:**
  * フォントファミリー名単体（例: `游ゴシック`）をコピー。
* **下部詳細「ファイル名: 」横「📋」:**
  * フォントファイルの完全パス（例: `C:\Windows\Fonts\YuGothR.ttc`）をコピー。
* **「📋 CSS をコピー」:**
  * `font-family: '游ゴシック', sans-serif;` 形式の CSS プロパティをコピー。
* **「📋 パスをコピー」:**
  * 選択中フォントのファイル絶対パス（例: `C:\Windows\Fonts\YuGothR.ttc`）をコピー。
* **リスト右クリックメニュー:**
  * 「📋 フォントファミリーをコピー」「📋 フォント名（スタイル含む）をコピー」「📋 CSS font-family をコピー」「📋 ファイルパスをコピー」

### プレビュー描画アーキテクチャ

* **描画エンジン:** **Microsoft.Web.WebView2 (Chromium / Blink)**
  * WPF 標準の `TextBlock` では対応できない **COLRv1 や SVG などの最新ベクター色絵文字（`Noto Color Emoji`、`Segoe UI Emoji` 等）を完全なフルカラーで正確に描画**。
  * スライダー操作（サイズ・太さ・文字幅・傾き）やテーマ切り替えは JavaScript の CSS 変数書き換え（`ExecuteScriptAsync`）により、チラつきのない 60fps レスポンスで高速同期。
* **OS タイトルバーのテーマ連動 (DWM):**
  * Windows の DWM API（`DwmSetWindowAttribute`）により、ウィンドウのタイトルバー（キャプションバー）の背景色および文字色を現在のテーマ（tal7aouy / spinel / dark / light）に完全同期。ダークモード／ライトモードのシステムボタン（最小化・最大化・閉じる）も自動追従。
* **文字幅 (wdth) スケーリング:**
  * 単語分割による余白発生を解消し、行コンテナ全体に対する CSS `transform: scaleX(...)` と文字幅連動計算により、文字詰めが等比率で詰まる DTP 準拠の組版を実現。バリアブルフォント対応時は `font-variation-settings: "wdth"` と連動。
* **フォント傾き (slnt) の描画:**
  * 平行四辺形変形（`skewX`）による複数行の行頭ズレを排除し、CSS Fonts Level 4 の **`font-style: oblique <角度>deg`** を採用。文字のベースラインを基準にグリフを傾けるため、左揃え垂直ラインが崩れない正確な斜体描画を実現。バリアブルフォントの `slnt` 軸対応時はスライダーで無段階傾斜調整（非対応フォントはスライダーを無効化）。
* **カラーテーマ:**
  * VS Code の人気テーマ **tal7aouy**（デフォルト）、**spinel**（Shopify Ruby）、**dark**、**light** の 4 テーマに対応。プレビュー背景・文字色も同期。
* **フォールバック文字判定（未収録文字の扱い）:**
  * フォント選択ツールとしての厳格性を保つため、異なるフォントを混ぜて表示（自動フォールバック）は行わず、選択フォントに含まれない文字は C# 側のグリフ判定（`OpenTypeReader` / `GlyphTypeface`）により確実に **「□」** として表示。
* **Airspace（エアスペース）対策:**
  * フォント初期読み込み中（`IsLoading == true`）は WebView2 を非表示（Collapsed）にし、プログレスオーバーレイへの突き抜け表示を防止。

### ディレクトリ・ソース配置方針

すべてのソースコードは **`src/`** 配下に集約・管理します。ルート直下にはビルドスクリプトやドキュメントのみを配置します。

```
font-selector/
├── FontSelector.slnx
├── build.bat                 # リリース用自己完結単一 exe 発行スクリプト
├── 方針.md                   # 本ドキュメント
├── publish/                  # 発行された単一 exe
├── scripts/
│   └── run.ps1               # 動作検証・メモリ測定スクリプト（固定名）
└── src/
    └── FontSelector/         # アプリケーションソースコード
        └── FontSelector/
            ├── App.xaml / MainWindow.xaml
            ├── Converters/
            ├── Models/       # FontFamilyInfo, TypefaceInfo, VariationAxis, LanguageTagItem
            ├── Services/     # FontService, OpenTypeReader, OpenType/*, SampleTextProvider, PreviewHtmlBuilder
            ├── Themes/       # Tal7aouy, Spinel, Dark, Light
            ├── ViewModels/   # MainViewModel
            └── Views/        # 各種コントロール (FontList, Preview, FilterBar, FontInfoPanel, SearchBar)
```

### ビルド・発行手順

#### 📍 通常ビルド（開発・デバッグ用）
```cmd
dotnet build
```
実行ファイル:
`src\FontSelector\FontSelector\bin\Debug\net10.0-windows\FontSelector.exe`

#### 💡 単一の独立した .exe として出力（配布・完全ポータブル用）
他の PC や別のフォルダに `.exe` 単体（1ファイルのみ）で持っていきたい場合、.NET ランタイムおよび WPF / WebView2 のネイティブ DLL をすべて内蔵した**自己完結型（Self-Contained）**の単一ファイルを出力できます：

```cmd
build.bat
```
または手動コマンド：
```cmd
dotnet publish src\FontSelector\FontSelector\FontSelector.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:DebugType=none -p:DebugSymbols=false -o publish
```

出力先:
`publish\FontSelector.exe`（約 136 MB、他 PC でもランタイム不要でそのまま起動可能）

不要ファイルの削除
```cmd
dotnet clean
```

### スクリプト実行方針
* PowerShell や Python ではワンライナー（`-Command "..."` や `-c "..."` など）を使用しないでください。
* スクリプトを実行する際は、毎回新しいファイル名を作成するのではなく、固定ファイル名（`scripts/run.ps1`）を作成・上書きして実行してください。
