# Firefox Selection Clean Copy (行番号削除コピー拡張機能)

Copilot やターミナル・コマンド出力からコードをコピーする際、**邪魔な行番号やプロンプト記号（`$ `, `> `）を自動除去**し、さらに **Ctrl+C が制限・禁止されている環境でも確実にコピー**できる Firefox 拡張機能 (Manifest V3) です。

---

## 🎯 解決できる課題

1. **Copilot / Webエディタで Ctrl+C が効かない・禁止されている**
   - Web ページ側の JavaScript (`e.preventDefault()`) で Ctrl+C が遮断されるケースがあります。
   - 本拡張機能は **右クリックコンテキストメニュー**、**選択時に現れるフローティングHUDボタン**、**コードブロック上部に自動挿入される全コピーボタン**、**キャプチャフェーズ (`useCapture: true`) によるショートカット (`Alt+C` / `Ctrl+C`)** で確実にバイパスします。

2. **長文プログラムでスクロールしないと全体が表示されない（仮想スクロール問題）**
   - Copilot 等の最新 Web UI では、画面内に見えている行だけが DOM に描画され、スクロールしないと上下の行が存在しない「仮想スクロール（Virtualization）」が採用されています。
   - 本拡張機能は **コード領域を内部でステップスクロール走査し、画面外の見えないコードも含めて全行を自動収集** してから行番号なしで一発コピーします。

3. **解説文（地の文）をコピーしたときに箇条書きの数字が消えてしまうのを防止**
   - `1. インストール手順` などの地の文・手順リストが選択された場合、AI判定・DOM解析により「地の文」と自動判別。
   - 行頭の数字や記号を誤って削除することなく、**元のテキスト・句読点・箇条書き番号を完全に保持** してコピーします。

4. **行番号が含まれてしまい実行や貼り付け時にエラーになる**
   - Copilot Web で頻出の「コードと行番号が交互に分離して出現する形式 (`import os\n2\nfrom...`)」や `1 | code`, `01: code`, `[1] code` を自動検出して削除します。
   - インデント（字下げ）やコードの構造は保持されます。

5. **ターミナルのプロンプト記号（`$ `, `> `, `# `）もオプションで除去**
   - コマンドをコピーしてそのまま実行したいときに便利です。

---

## 🚀 4つのコピー方法

| 方法 | 操作 | 特徴 |
| :--- | :--- | :--- |
| **1. 自動注入「行番号なし全コピー」ボタン** | Copilot のコードブロック上部に出現するボタンをクリック | スクロールが必要な長文コードも自動走査して全体を行番号なしで一括コピー |
| **2. フローティングHUD** | テキスト選択すると選択位置の上にボタンが出現 | 地の文なら「地の文をコピー」、コードなら「行番号なしコピー」「全体を走査コピー」が賢く切替 |
| **3. ショートカットキー** | `Alt + C` または `Ctrl + C` (自動キャプチャ) | ページの `keydown` イベントリスナーより先回りして取得 |
| **4. 右クリックメニュー** | テキスト選択 ➔ 右クリック ➔ `📋 行番号を除去してコピー` | 右クリック禁止ページでもキャプチャ相上書き＆Shift+右クリックで利用可能 |

## 📦 Firefox への導入手順 (1分で完了)

1. **Firefox を起動**
2. アドレスバーに以下を入力して Enter を押します:
   ```text
   about:debugging#/runtime/this-firefox
   ```
3. 画面内の **「一時的なアドオンを読み込む... (Load Temporary Add-on...)」** ボタンをクリックします。
4. このフォルダ内の **`manifest.json`** を選択します。
5. ツールバーに本拡張機能のアイコンが表示され、すぐに使用可能になります！

> 💡 **常に利用したい場合 (永続化)**:
> Firefox Developer Edition または Nightly で `xpinstall.signatures.required = false` に設定するか、[addons.mozilla.org (AMO)](https://addons.mozilla.org/) のアドオン開発者ハブで自己配布用に署名 (Sign) することで、通常の Firefox でも永続インストールできます。

## ⚙️ 設定変更
Firefox のツールバーにある拡張機能アイコンをクリックすると、以下の設定を切り替え可能です:

### 1. ドメイン指定（完全ホワイトリスト方式）
- **未登録サイトでは一切動作しない安全設計**: 初期状態や未登録のサイトでは本拡張機能の全機能（コピーボタン・ショートカット等）が完全に停止しています。
- **現在のサイトをワンクリックで登録/解除**: 利用したいWebサイトでポップアップを開き、トグルスイッチを ON にするだけで即座に登録・有効化されます。
- **有効ドメインリスト**:
  - 利用したい任意のドメインを手動で追加・削除可能。


### 2. クリーニング設定
- **行番号の削除 (ON/OFF)**: 1 |, 1:, 01 などを自動検出して削除。
- **プロンプト記号の削除 (ON/OFF)**: $, >, # などのシェル記号を削除。
- **フローティングコピーボタンの表示 (ON/OFF)**: テキスト選択時のHUD表示。
- **Ctrl+C キャプチャ優先 (ON/OFF)**: ページ側の Ctrl+C 禁止スクリプトを突破。

## ❓ よくある質問: `about:debugging` で「バックグラウンドスクリプト (停止中)」と表示される場合

### Q. 「バックグラウンドスクリプト (停止中)」と表示されますが、動いていないのでしょうか？
**A. 正常に動作しています。ご安心ください。**

1. **Firefox Manifest V3 (MV3) の省電力設計**:
   - Firefox MV3 では、ブラウザのメモリ消費を減らすため、バックグラウンドスクリプトは常時メモリを消費するのではなく、必要なイベント（Alt+C や右クリックメニュー選択など）が発生した時にミリ秒で即座に起動し、待機時に休止する「イベントページ方式」がブラウザ標準の仕様です。
   - そのため、しばらく操作がないと Firefox の画面上で「停止中」と表示されますが、機能が停止したわけではありません。

2. **本拡張機能に実装されている強化対策**:
   - **Keep-Alive ハートビート通信**: Web ページ側（`content.js`）からの定期ポーリングと `browser.alarms` による起床シグナルで、待機停止を最小限に抑制します。
   - **既存タブへの自動注入 (Auto-Injection)**: アドオンを読み込んだ時点で既に開いていたタブ（Copilot 等）へスクリプトが自動注入されるため、ページのリロード不要で即座に機能します。
   - **ページ側での高速直接処理**: Copilot 上の「行番号なし全コピー」ボタンやテキスト選択HUD、Ctrl+C のキャプチャはページ側（`content.js`）で直接動作するため、バックグラウンドスクリプトの状態にかかわらずいつでも瞬時にコピーできます。
