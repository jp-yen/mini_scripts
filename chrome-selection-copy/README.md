# Selection Clean Copy (Chrome 拡張機能)

> Copilot や各種Webサイトのコード表示から行番号・プロンプト記号を除去し、Ctrl+C禁止環境でも確実にコピーできるChrome拡張機能（Manifest V3対応）です。

## 主な特徴

- **行番号の自動検出・除去**: Copilotの分離行番号、行頭の `1 |`, `[1]`, `1: ` などを自動判別して除去
- **「行番号なし全コピー」ボタンの自動注入**: Copilotなどのコードブロック右上にボタンを配置し、仮想スクロール全体を走査してワンクリックでコードのみを収集コピー
- **テキスト選択時のフローティングメニュー**: テキスト選択時にワンクリックでクリーンコピー可能なHUDを表示
- **完全ホワイトリスト方式**: 登録したドメインでのみ動作（未登録サイトでは一切動作しないため、意図しない干渉を防ぎます）
- **Copilot iframe 自動連動**: `copilot.microsoft.com` を登録すると、チャット埋め込みエンジン（`edgeservices.bing.com` 等）も自動で連動動作

## インストール手順 (Chrome)

1. Google Chrome を開き、アドレスバーに `chrome://extensions` と入力して Enter を押します。
2. 右上の **「デベロッパー モード」** を ON にします。
3. 左上に表示される **「パッケージ化されていない拡張機能を読み込む」** をクリックします。
4. 本フォルダ（`chrome-selection-copy`）を選択して読み込みます。
5. ツールバーのパズルアイコンから「Selection Clean Copy」をピン留めします。

## Edge でのインストール手順
1. Microsoft Edge を開き、アドレスバーに edge://extensions と入力して Enter を押します。
2. 左側サイドバー（または画面下部）にある 「開発者モード」 のトグルを ON にします。
3. 画面上部に表示される 「展開して読み込む」（または「パッケージ化されていない拡張機能を読み込む」）ボタンをクリックします。
4. フォルダ選択ダイアログで、先ほど作成した d:\GIT-HUB\mini_scripts\chrome-selection-copy を選択します。
5. ツールバーのパズルピースアイコンから「Selection Clean Copy」をピン留めすれば完了です。

## 使い方

1. **ドメインの有効化**:
   - 拡張機能アイコンをクリックしてポップアップを開きます。
   - 現在表示しているサイトを有効化する場合は「このサイトで拡張機能を有効化」のトグルを ON にします。
   - または「有効ドメイン管理」から `copilot.microsoft.com` などを手動追加します。
2. **コピー操作**:
   - **コードブロック**: コード枠内に自動注入される「📋 行番号なし全コピー」をクリック
   - **選択コピー**: テキストを選択してポップアップするフローティングボタンをクリック、または `Alt + C`
   - **コンテキストメニュー**: 選択範囲を右クリックして「📋 行番号を除去してコピー」を選択

## ファイル構成

- `manifest.json`: Chrome Manifest V3 設定ファイル (Service Worker対応)
- `background.js`: バックグラウンドサービスワーカー（コンテキストメニュー、特権書き込み、Keep-Alive）
- `content.js`: コンテンツスクリプト（DOM解析、行番号除去、仮想スクロール走査、ボタン注入）
- `content.css`: 注入ボタン・フローティングHUD・トースト通知のスタイル
- `popup.html` / `popup.css` / `popup.js`: ドメイン管理・設定変更ポップアップ
- `icons/`: アイコンファイル
