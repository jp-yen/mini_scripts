# Editor Rename Tool

テキストエディターを利用して、多数のファイルを一括で名前変更または移動するWindows用ツールです。

Vim、GVim、EmEditorなど、普段使用しているエディターの検索、置換、正規表現、マクロ、矩形編集などをそのまま利用できます。

## 動作環境

本ツールは **C#版（.exe）** と **PowerShell版（.ps1）** の2つの実装を提供しています。お使いの環境や運用ポリシーに合わせて選択できます。

- Windows 10 または Windows 11
- .NET Framework 4.0 以上（Windows 10/11 標準搭載）
- Windows PowerShell 5.1（PowerShell版使用時のみ）
- Vim、GVim、EmEditor などの任意のテキストエディター

> [!TIP]
> **どちらを使うべきか？**
> - **C#版（推奨）**: 実行ポリシー（`ExecutionPolicy`）の制限がある環境でも単体で確実に動作します。コンパイル済み exe が同梱されているほか、Windows 標準の `csc.exe` で追加ツールなしで再ビルド可能です。
> - **PowerShell版**: スクリプトのまま中身を確認・編集したい環境で手軽に利用できます。

## ファイル構成

本リポジトリには、C#版とPowerShell版の両方の関連ファイルが含まれています。

```text
EditorRenameTool\
├─ 【C#版（推奨 / exe実行版）】
│   ├─ EditorRenameTool.cs    # C# ソースコード
│   ├─ EditorRenameTool.exe   # コンパイル済み実行ファイル本体
│   ├─ build.bat              # Windows標準のcsc.exeによるビルドバッチ
│   ├─ Install.bat            # 「送る」メニューへのショートカット登録バッチ
│   └─ Uninstall.bat          # ショートカット解除バッチ
│
├─ 【PowerShell版（ps1スクリプト版）】
│   ├─ EditorRenameTool.ps1   # PowerShellスクリプト本体
│   ├─ Install.ps1            # インストール用PowerShellスクリプト
│   └─ Uninstall.ps1          # アンインストール用PowerShellスクリプト
│
└─ README.md                  # 本ドキュメント
```

## インストール前の確認

### C#版を使用する場合
- 同梱の `EditorRenameTool.exe` をそのまま利用できます。
- ソースコードから自分でビルドしたい場合は、`build.bat` をダブルクリックするだけで、Windows標準搭載の `csc.exe` を使って即座にビルドされます（Visual Studio等の追加ツールは不要です）。

### PowerShell版を使用する場合
- PowerShellスクリプト（`.ps1`）は、UTF-8 with BOMで保存することを推奨します。
- 各スクリプトの拡張子が誤って `.txt`（例: `EditorRenameTool.ps1.txt`）になっていないことを確認してください。

## インストール

いずれの版も管理者権限は不要です。

### 1. C#版のインストール（推奨）

`Install.bat` をダブルクリックして実行します。

- 「送る（SendTo）」メニューに「エディターで名前変更または移動」ショートカットが作成されます。
- `EditorRenameTool.exe` が未ビルドの場合は自動で `build.bat` を呼び出し、コンパイル完了後に登録されます。
- PowerShellスクリプトの実行制限がある環境でも問題なく動作します。

### 2. PowerShell版のインストール

`Install.ps1` を右クリックし、次を選択します。

```text
PowerShellで実行
```

実行ポリシーによって起動できない場合は、Windows PowerShellを開き、保存したフォルダーへ移動して次を実行します。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -STA -File .\Install.ps1
```

PowerShell版では、スクリプト本体が `%LOCALAPPDATA%\EditorRenameTool\` へコピーされ、「送る」メニューおよびスタートメニューにショートカットが作成されます。

## エディターの登録

インストール後、管理画面が起動します。

次のボタンを押します。

```text
エディター設定...
```

［参照］ボタンを押し、使用するエディターの実行ファイルを選択してください。

### EmEditorの例

インストール方法によって異なりますが、一般的には次のような場所です。

```text
C:\Program Files\EmEditor\EmEditor.exe
```

### GVimの例

バージョンによってフォルダー名が異なります。

```text
C:\Program Files\Vim\vim91\gvim.exe
```

### 起動引数

標準設定は次のとおりです。

```text
"{file}"
```

`{file}` は、ツールが作成した編集一覧ファイルのフルパスに置き換えられます。

登録する起動引数には、必ず `{file}` を含めてください。

## 編集完了の通知とタブ式エディターへの対応

VS Code、Notepad++、Sublime Text、EmEditorなどのタブ式エディターや、既存プロセスを共有するエディターでも確実に動作するよう、本ツールでは**アプリ側の待機画面**で編集完了を検知します。

1. エディターで一覧ファイルを開くと同時に、アプリ側で「編集待機中」画面が表示されます。
2. エディター上で右側のファイルパスを編集し、一覧ファイルを**上書き保存**します（エディターを閉じる必要はありません）。
3. 保存後、アプリ側の**［編集完了（プレビューへ進む）］**ボタンをクリックします。
4. ファイル名の変更・移動内容をまとめた「プレビュー」画面が表示されます。
   - 変更前と変更後のパスが見比べやすいよう、上下に並べて表示されます（ラベルは「変更前:」が赤色、「変更後:」が緑色。パス本体は上下同じフォントで表示され、差異がない部分は文字位置が揃って見比べやすくなっています）。
   - ［パスをコピー］ボタンや Ctrl+C キーで選択項目のパスをクリップボードへコピーすることも可能です。
5. 内容を確認して［実行］をクリックすると、実際の名前変更・移動処理が行われます。

> [!TIP]
> - エディターのタブを誤って閉じてしまった場合でも、待機画面の**［エディターを再度開く］**ボタンからすぐに開き直せます。
> - 処理を取り消したい場合は、［キャンセル］ボタンを押すだけで安全に終了します。
> - プロセス終了（`WaitForExit`）に依存しないため、タブ式エディターやシングルインスタンス型エディターでも終了検知の不具合が発生しません。

## ファイル名の変更と移動

本ツールは、**「送る」メニュー**からの起動と、**アプリ画面へのドラッグ＆ドロップ**の両方に対応しています。

### 方法1: アプリ画面へのドラッグ＆ドロップ（推奨：大量のファイルにも対応）

Windowsの「送る」メニューは、コマンドライン引数の最大長（約8,191文字）の制限を受けるため、選択したファイルのパス合計が長い場合に起動できないことがあります。
アプリ画面へファイルをドラッグ＆ドロップすることで、パス長の制限を受けずに数千件以上のファイルも一括で登録できます。

1. スタートメニューの「Editor Rename Tool」または本体（`EditorRenameTool.exe` / `EditorRenameTool.ps1`）を起動します。
2. エクスプローラーから変更したいファイルまたはフォルダーを、画面の一覧領域へ**ドラッグ＆ドロップ**します。
   - 別のフォルダーにあるファイルも、複数回ドロップして追加できます。
   - フォルダーをドロップした場合は、フォルダー内のファイルを自動展開します（「サブフォルダーも含める」にチェックを入れると階層下のファイルもすべて追加されます）。
   - ［ファイル追加...］や［フォルダー追加...］ボタンから選択して追加することも可能です。
   - 重複するファイルは自動的にスキップされます。
3. ［エディターで名前変更を開始］ボタンをクリックします。
4. 登録したエディターが起動し、同時にアプリ側に「編集待機中」画面が表示されます。

> [!TIP]
> エディター起動後の「編集待機中」画面に対しても、追加したいファイルを直接ドラッグ＆ドロップして一覧を拡張できます。

### 方法2: エクスプローラーの「送る」メニューから実行

少数のファイルを手軽にリネームする場合は、従来通り「送る」メニューも便利です。

1. エクスプローラーで、対象となる複数のファイルを選択します。
2. 右クリック →［送る］→［エディターで名前変更または移動］を選択します。
3. 登録したエディターが起動し、編集待機画面が表示されます。

---

### エディターでの編集

エディターが起動すると、次のような一覧が表示されます。

```text
# 左側のIDとタブは変更しないでください。右側のフルパスだけを編集します。
# 変更しないファイルは行ごと削除できます。行の並べ替えも可能です。
F00000001	C:\Work\photo001.jpg
F00000002	C:\Work\photo002.jpg
F00000003	C:\Work\photo003.jpg
```

IDとファイルパスの間はタブです。

## ファイル名だけを変更する例

元の一覧:

```text
F00000001	C:\Work\photo001.jpg
F00000002	C:\Work\photo002.jpg
F00000003	C:\Work\photo003.jpg
```

編集後:

```text
F00000001	C:\Work\20261010_photo001.jpg
F00000002	C:\Work\20261010_photo002.jpg
F00000003	C:\Work\20261010_photo003.jpg
```

保存してエディターを閉じると、3ファイルの名前変更予定が表示されます。

## 別のディレクトリへ移動する例

編集後:

```text
F00000001	C:\Archive\2026\10\photo001.jpg
F00000002	C:\Archive\2026\10\photo002.jpg
F00000003	C:\Archive\2026\10\photo003.jpg
```

次のディレクトリが存在しない場合は、自動的に作成されます。

```text
C:\Archive\2026\10
```

## 名前変更と移動を同時に行う例

```text
F00000001	C:\Archive\2026\10\event_photo001.jpg
F00000002	C:\Archive\2026\10\event_photo002.jpg
F00000003	C:\Archive\2026\10\event_photo003.jpg
```

ファイル名変更とディレクトリ移動が同時に行われます。

## 変更しないファイル

変更する必要がないファイルは、該当する行を削除します。

元の一覧:

```text
F00000001	C:\Work\a.txt
F00000002	C:\Work\b.txt
F00000003	C:\Work\c.txt
```

編集後:

```text
F00000002	C:\Work\b_new.txt
```

削除された行に対応する `a.txt` と `c.txt` には、何も処理を行いません。

## 行の並べ替え

IDで元ファイルとの対応を管理しているため、エディター内で行を並べ替えても問題ありません。

```text
F00000003	C:\Archive\c.txt
F00000001	C:\Archive\a.txt
F00000002	C:\Archive\b.txt
```

※ 左側のIDは変更しないでください。

## ファイル名の入れ替え

次のような名前の入れ替えにも対応しています。

元の状態:

```text
A.txt
B.txt
```

編集後:

```text
F00000001	C:\Work\B.txt
F00000002	C:\Work\A.txt
```

ツールは一度作業用の一時ファイルへ退避したあとで最終的な移動先へ移動するため、循環や入れ替えも安全に実行されます。

## 実行前プレビュー

エディターを保存して閉じると、実際に変更するファイルの一覧プレビューが表示されます。

内容を確認して、［はい］を押すと処理を実行します。

［いいえ］を押すと、ファイル名の変更や移動は行わずに終了します。

変更対象が多い場合、プレビューには先頭20件と残りの件数が表示されます。

## エラーになる主な条件

次のような場合は処理が失敗またはスキップされます。

- 元のファイルが存在しない
- 移動先に同名のファイルまたはフォルダーが既に存在する
- 複数のファイルに同一の移動先が指定されている
- 対象ファイルが他のアプリケーションでロックされている
- 移動元または移動先フォルダーへのアクセス権限がない
- ネットワークドライブが切断されている
- IDが変更されている、または存在しないIDが指定されている
- IDが重複している
- IDとファイルパスの間のタブ文字が削除されている
- ファイルパスにWindowsで使用できない文字が含まれている

## 失敗項目の再試行

一部の処理に失敗した場合、失敗件数と理由が表示されます。

その後、失敗した項目だけをエディターで開いて再試行するか確認ダイアログが表示されます。

［はい］を選択すると、失敗項目だけの一覧が再度エディターで開きます。

```text
F00000012	C:\Archive\duplicate.txt
F00000035	C:\Archive\locked.txt
```

移動先を修正し、保存してエディターを閉じると再試行できます。

再試行しない項目は、該当行を削除してください。

## Undo（元に戻す）

スタートメニューから起動します。

```text
Editor Rename Tool
```

管理画面で次のボタンを押します。

```text
Undo履歴...
```

履歴選択画面には、実行日時、件数、種別が表示されます。

```text
2026-10-10 13:40:20      325 件  [Rename]
2026-10-10 12:18:03       42 件  [Rename]
2026-10-09 18:02:51      816 件  [Retry]
```

元に戻したい履歴を選択し、次を押します。

```text
選択履歴を元に戻す
```

Undoのプレビューが表示されます。

内容を確認して［はい］を押すと、移動済みのファイルが元のパスへ戻ります。

## Undoの動作

例えば、次の変更を行ったとします。

```text
C:\Work\a.txt
  → C:\Archive\new-a.txt
```

履歴には次の情報が保存されます。

元の場所:

```text
C:\Work\a.txt
```

現在の場所:

```text
C:\Archive\new-a.txt
```

Undoでは、逆の処理を行います。

```text
C:\Archive\new-a.txt
  → C:\Work\a.txt
```

同名ファイルのUndoでも、一度一時ファイルへ退避してから元の名前に戻します。

## Undoが失敗する場合

次のような場合、Undoを実行できない可能性があります。

- リネーム後のファイルが手動で削除された
- リネーム後のファイルが手動で別の場所へ移動された
- 元のファイル名と同名のファイルが新しく作成された
- ファイルが別のアプリケーションで使用中
- ネットワークドライブが切断されている
- アクセス権限が変更された

Undoに失敗した項目は、通常のリネーム同様にエディターで再編集して再試行できます。

## 履歴ファイル

履歴はJSON形式で、次のフォルダーに保存されます。

```text
%LOCALAPPDATA%\EditorRenameTool\History
```

履歴には、成功したファイルのみ記録されます。

主な情報は次のとおりです。

```text
セッションID
実行日時
処理種別
元のファイルパス
変更後のファイルパス
Undo済みかどうか
```

Undoを実行すると、その履歴にもUndo済みの情報が記録されます。

## 設定および作業ファイルの保存場所

```text
%LOCALAPPDATA%\EditorRenameTool\
```

構成:

```text
EditorRenameTool\
├─ EditorRenameTool.ps1
├─ config.json
├─ application.log
├─ History\
│   └─ 実行履歴JSONファイル
└─ Work\
    └─ エディターで編集した一覧ファイル
```

### config.json

選択したエディターの実行ファイルパスと起動引数を保存します。

### History

リネーム、移動、再試行、Undoの実行履歴をJSON形式で保存します。

### Work

エディターで編集した作業用の一覧ファイルを保存します。一覧を後から確認できるよう、現バージョンでは自動削除しません。

### application.log

予期しないエラーのスタックトレースやログを記録します。

## 現在の制限

### ファイルのみ対応

現在のバージョンでは、ファイルを対象にしています。フォルダー自体の名前変更には対応していません。フォルダーを「送る」へ渡した場合、そのフォルダー内のファイルは自動展開されません。

### 保存検知は使用しない

編集一覧を保存した瞬間には処理を実行しません。次の流れで処理します:

```text
エディター起動 ＆ 編集待機画面の表示
  → 一覧編集
    → 保存
      → ［編集完了（プレビューへ進む）］ボタンをクリック
        → プレビュー表示
          → 実行
```

編集中に誤って途中保存した場合でも即座に実行されることはなく、必ず［編集完了（プレビューへ進む）］ボタンが押されるまで待機します。

### 移動元ディレクトリは削除しない

ファイル移動後に空になった移動元フォルダーは、自動削除しません。必要なフォルダーを誤って削除する危険を避けるためです。

### すべての状態で完全に元に戻せるわけではない

外部でファイルが削除、上書き、手動移動された場合は、Undoで元に戻せないことがあります。このツールのUndoはバックアップ復元ではなく、記録されたパスと現在パスを使って逆方向の移動を行う機能です。

## 安全のための注意

- 重要なファイルで使用する前に、必ずコピーしたテスト用ファイルで動作を確認してください。
- 特に次のような場合は事前の動作確認を強く推奨します:
  - 1万件以上のファイルがある場合
  - ネットワークドライブ上のファイル
  - OneDriveなどのクラウド同期フォルダー
  - アクセス権限が制限されたフォルダー
  - ファイルの拡張子を一斉変更する場合
  - 別のドライブへ大量のファイルを移動する場合

## アンインストール

### C#版のアンインストール

`Uninstall.bat` をダブルクリックして実行します。
「送る」メニューからショートカットが削除されます。

### PowerShell版のアンインストール

`Uninstall.ps1` を右クリックし、次を選択します。

```text
PowerShellで実行
```

またはWindows PowerShellから実行します。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -STA -File .\Uninstall.ps1
```

PowerShell版のアンインストール時には、設定と履歴を削除するか確認ダイアログが表示されます。

### ［はい］

次の項目をすべて削除します。

- 「送る」メニューのショートカット
- スタートメニューのショートカット
- インストール本体 (`%LOCALAPPDATA%\EditorRenameTool\EditorRenameTool.ps1`)
- エディター設定
- Undo履歴
- 編集用一覧
- アプリケーションログ

### ［いいえ］

次の項目のみ削除します。

- 「送る」メニューのショートカット
- スタートメニューのショートカット
- インストール本体 (`%LOCALAPPDATA%\EditorRenameTool\EditorRenameTool.ps1`)

エディター設定、Undo履歴、編集用一覧、ログは残ります。

### ［キャンセル］

アンインストールを中止します。

## 最初のテスト手順

安全に確認するため、次のようなテスト用フォルダーを作成します。

```text
C:\RenameTest\
├─ a.txt
├─ b.txt
└─ c.txt
```

3ファイルを選択して、右クリックの［送る］→［エディターで名前変更または移動］からツールを起動します。

編集一覧を次のように変更します。

```text
F00000001	C:\RenameTest\Archive\new-a.txt
F00000002	C:\RenameTest\Archive\new-b.txt
```

※ 3行目は削除します。

保存後、アプリ側の［編集完了（プレビューへ進む）］を押し、プレビュー画面で内容を確認して［実行］を押します。

期待される結果:

```text
C:\RenameTest\
├─ c.txt
└─ Archive\
    ├─ new-a.txt
    └─ new-b.txt
```

続いて、スタートメニューから `Editor Rename Tool` を起動します。

```text
Undo履歴...
  → 直前の履歴を選択
    → 選択履歴を元に戻す
```

期待される結果:

```text
C:\RenameTest\
├─ a.txt
├─ b.txt
└─ c.txt
```

※ `Archive` フォルダーは空になりますが、自動削除されません。
