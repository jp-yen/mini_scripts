# GnuPG UI (GPG-UI) 開発目的と設計仕様

## 1. 目的 (Purpose)

Windows11 に最初から含まれる機能 (.NET Framework 4.0 付属 csc.exe) のみでビルドできること。

GnuPG (GNU Privacy Guard) のコマンドライン操作を直感的な日本語の Windows デスクトップ GUI (C# / WPF アプリケーション) で操作できるようにするアプリケーションの提供。

暗号化、復号、鍵ペア作成、公開鍵/秘密鍵の管理、署名および検証などの一連の暗号操作を、シンプルなインターフェースで安全に実行できるようにすることを目標とする。
WebUI プレビューは不要です。

## 2. 主な機能仕様 (Key Features)

### 2.1 鍵保管庫 (Key Management)

- **鍵一覧表示**: パブリックキー（公開鍵）およびシークレットキー（秘密鍵）の一覧、詳細情報（ユーザーID、メールアドレス、キーID、フィンガープリント、作成日、有効期限、アルゴリズム）の視覚的表示。
- **鍵の検索・フィルタ**: 名前、メール、キーID、フィンガープリントでの高速フィルタリング。ウィンドウ幅に応じて伸縮するレスポンシブな検索バー。
- **鍵の署名（認証）**: 自身の秘密鍵を用いて他の公開鍵にデジタル署名（完全署名 `--sign-key` / ローカル署名 `--lsign-key`）を行い、Web of Trust 信頼レベルを更新可能。
- **新規鍵ペア生成**: ユーザー名、メールアドレス、コメント、有効期限、パスフレーズを設定した鍵ペア生成。**セキュリティ上の観点から、RSA や NIST 曲線などの旧世代/レガシーアルゴリズムは作成不可とし、現代的で安全な Ed25519 (Curve25519) および Ed448 (Cv448) のみに限定**。
- **鍵のインポート**: ASCII Armor 形式テキストの貼り付け、または `.asc` / `.gpg` / `.pub` / `.key` ファイルのドラッグ＆ドロップによる鍵の取り込み。
  ASCII 形式の鍵のインポートは https://docs.freebsd.org/pgpkeys/pgpkeys.txt のテキストを貼り付けて一括インポート可能。キーストア検索にも対応。
- **鍵のエクスポート**: 公開鍵・秘密鍵の ASCII Armor 表示、ワンクリックコピー、ファイルダウンロード。
- **鍵の削除**: 単一または複数選択（Ctrl / Shift 選択）された公開鍵・秘密鍵の安全な一括削除機能。


### 2.2 暗号化・復号 (Encryption & Decryption)

- **テキスト暗号化**: 任意のテキストを入力し、送信者署名鍵、受信者の公開鍵（複数選択可）、または共通鍵パスフレーズを指定して ASCII Armor 暗号文を生成。
- **ファイル・フォルダーの暗号化**:
  - 単一ファイル、**複数ファイルの一括選択/ドロップ**、および**フォルダー（ディレクトリ構造全体）**の暗号化に対応。
  - **自動ZIPアーカイブ化**: 複数ファイル/フォルダー、またはフォルダー単体が指定された場合は、自動的に 1 つの ZIP アーカイブにまとめて圧縮した上で GnuPG 暗号化を実施。
  - **出力形式の選択**: ASCII Armor (`.asc`) とバイナリ (`.gpg`) をコンボボックスで選択可能。保存ダイアログのデフォルト拡張子およびフィルターも選択に合わせて自動連動。
- **ステップ順の安心ワークフロー**:
  - ファイル/フォルダーをドロップしても即座にダイアログが開くことはなく、パスおよびアイテム数（ファイル/フォルダーの内訳）を入力欄に保持して待機。
  - ユーザーが【送信者の署名鍵】【署名用パスフレーズ】【受信者の公開鍵】【共通鍵パスフレーズ】【出力形式】を十分に確認・指定した後に「暗号化を実行」ボタンを押すことで `SaveFileDialog` が起動。
- **視認性の高い受信者選択**: 公開鍵リスト選択時は、ダークテーマに合わせた視認性の高いブルー背景とシアンアクセント線で選択状態を明確化。
- **テキスト/ファイル復号**: 暗号化テキストまたは `.asc` / `.gpg` ファイルを入力し、パスフレーズを入力して復号文・復号ファイルを取得。署名付き暗号文の場合は署名者情報（Fingerprint, UID）も自動検証。
- **上書き安全設計**: 復号ファイルの保存時は常に `SaveFileDialog` を開いて保存先とファイル名を確認・指定。

### 2.3 署名・検証 (Signature & Verification)

- **デジタル署名**: タブ「署名」からクリアテキスト署名 (`--clear-sign`)、分離署名 (`--detach-sign`)、バイナリ署名の生成。
- **厳格な署名検証**:
  - タブ「検証」から署名付き文書または検証対象ファイル＋署名ファイルを読み込み、署名の有効性を検証。
  - **署名偽装対策**: 人間用テキストのログ解析ではなく、GnuPG の機械可読ステータスタグ (`[GNUPG:] VALIDSIG`, `GOODSIG`) のみを厳密解析することで署名偽装攻撃を完全防止。

### 2.4 ダッシュボード＆システム情報 (Dashboard & Status)

- GnuPG のバージョン情報 (`gpg 2.5.x`等) やサポートアルゴリズム、インストール状態の確認。
- 登録鍵数（公開鍵・秘密鍵）のサマリー表示。

## 3. セキュリティ設計・堅牢化 (Security Design)

- **一時ファイルのゼロ上書き消去 (Secure Delete)**: フォルダー暗号化時の作業用一時 ZIP ファイルや検証用一時ファイルは、削除前に全データをゼロバイト上書き消去。
- **プロセスコマンドインジェクション防止**: 16進数文字サニタイズ (`SanitizeHex`)、バッチパラメータサニタイズ (`SanitizeBatchParam`) により外部入力を厳密保護。
- **パスフレーズの安全な受渡**: コマンドライン引数ではなく stdin (`--passphrase-fd 0`) 経由でプロセスに渡すことで引数履歴露出を防止。
- **予測不能な一時ファイル生成**: 一時ファイル作成時は `Guid` を用いたランダムパスを使用し、TOCTOU 攻撃を防御。

## 4. ファイル構成と役割 (File Structure & Roles)

### Core Components

- **`Program.cs`**: アプリケーションのエントリポイント。WPF アプリケーションインスタンスの起動、グローバルテーマの適用、およびコマンドライン引数（起動時ドロップファイル）の判定・渡す処理を担当。
- **`MainWindow.cs`**: メインウィンドウ。サイドバーナビゲーション（ダッシュボード・鍵保管庫・暗号化・復号化・署名・検証）、コンテンツ画面の切り替え、およびファイル/フォルダーがウィンドウ全体へドロップされた際のスマートルーティングを担当。
- **`GpgService.cs` / `Services/`**: GnuPG コマンドラインツール (`gpg.exe`) とのプロセス間連携コアエンジン。Partial クラス分割（`Crypto`, `Keys`, `SignVerify`）により責務を分離。鍵のリスト取得・生成・インポート・エクスポート・署名・削除、テキスト/ファイル/フォルダーの暗号化・復号、署名・検証ロジックを統括。
- **`GpgModels.cs`**: 鍵情報 (`GpgKey`, `GpgSubkey`, `GpgUid`)、暗号化/復号結果 (`CryptoResult`, `VerifyResult`) 等のデータモデル定義。暗号化利用可否 (`IsUsableForEncryption`) の判定ロジックを含む。
- **`ThemeHelper.cs`**: アプリ全域の共通デザインテーマ（Slateダークテーマ）コンポーネント。UIカラーパレット、スタイリングされたボタン・テキストボックス・パスワードボックス・ダイアログの動的生成、および XAML リソースディクショナリの適用を担当。
- **`build.bat`**: Windows 11 標準組み込みの C# コンパイラ (`csc.exe`) を用いて外部開発環境（Visual Studio 等）なしで `GpgUi.exe` を直接コンパイル・ビルドする自動化スクリプト。

### Views (UI Screens & Windows)

- **`Views/CryptoView.cs` / `CryptoView.Encrypt.cs` / `CryptoView.Decrypt.cs`**: 「暗号化・復号化」画面（タブ: 「暗号化 (ファイル・フォルダ)」「暗号化 (テキスト)」「復号化」）。テキストおよびファイル/フォルダーの暗号化、出力形式選択（`.asc` / `.gpg`）、送信者（署名鍵・パスフレーズ）および受信者（公開鍵・共通鍵）の指定、ファイルの復号、上書き防止付き保存を担当。
- **`Views/KeyManagerView.cs`**: 「鍵保管庫」画面。公開鍵・秘密鍵の一覧表示、レスポンシブな検索・フィルタリング、鍵の詳細情報（アルゴリズム、有効期限、鍵ID、フィンガープリント）確認、他鍵への署名認証ダイアログ呼び出し、公開鍵/秘密鍵のエクスポートおよび削除操作を担当。
- **`Views/SignVerifyView.cs`**: 「署名・検証」画面（タブ: 「署名」「検証」）。クリアテキスト署名・分離署名・バイナリ署名の生成、および署名付き文書や検証対象ファイルの検証（`VALIDSIG`/`GOODSIG` による機械可読タグ検証）を担当。
- **`Views/DashboardView.cs`**: 「ダッシュボード」画面。登録鍵数（公開鍵・秘密鍵）のサマリーカード表示、GnuPG バージョン・実行ファイルパス・ホームディレクトリ等の動作ステータス表示を担当。
- **`Views/KeyGeneratorWindow.cs`**: 「新規鍵ペア生成」モーダルダイアログ。Ed25519 / Ed448 現代的鍵ペアの作成パラメータ入力（名前、メール、コメント、有効期限、パスフレーズ）と生成要求を担当。
- **`Views/KeyImportWindow.cs`**: 「鍵インポート」モーダルダイアログ。ASCII Armor 鍵テキストの貼り付け、鍵ファイル (`.asc`, `.gpg`, `.pub`等) のドロップ、またはキーストア検索による鍵の取り込み処理を担当。
- **`Views/SettingsWindow.cs`**: 「GnuPG システム設定」モーダルダイアログ。`gpg.exe` の実行ファイルパス変更・参照指定、および動作接続テストを担当。
